Listing in the directory

The directory on khaytapp.com shows shops what an item does before they install it. A listing is your words, links and pictures. What the item may do comes only from its signed manifest.

What a listing holds

listing.json
{
  "id": "com.example.courier",
  "kind": "connector",
  "name": "Example Courier",
  "publisher": {
    "name": "Example Logistics",
    "namespace": "com.example"
  },
  "summary": "Book a pickup from a finished job and get the tracking number back.",
  "description": "Adds a Book pickup button to a job. Sends the customer’s name, phone and address to api.example.com, and fills in the tracking number from the reply.",
  "category": "shipping",
  "licence": "MIT",
  "source": "https://github.com/example/khayt-courier",
  "privacy": "https://example.com/privacy",
  "support": "mailto:help@example.com",
  "screenshots": [
    {
      "url": "https://example.com/khayt/book-pickup.png",
      "alt": "The Book pickup button on a finished job"
    }
  ]
}
Listing keys
KeyRequiredMeaning
idRequiredThe item’s id: the manifest’s id for a connector. It must sit under your publisher namespace.
kindRequiredOne of connector, addon, plugin, slicer. Only connector can be installed today; the others list as “coming”.
nameRequiredThe name on the card and the page, up to 60 characters.
publisherRequiredYour publisher name and namespace. The page shows the name and the verified badge from Khayt’s publisher record, never from this.
summaryRequiredOne line for the card, up to 140 characters.
descriptionOptionalOptional: the page’s text, up to 4000 characters. Shown as plain text: no HTML, no markdown.
descriptionArOptionalOptional: the same in Arabic. Without it, the Arabic page shows the English, set left to right.
categoryRequiredOne of shipping, payments, messaging, accounting, storefront, productivity, slicer, other.
licenceRequiredAn SPDX identifier, such as MIT.
sourceOptionalAn https link to the source. Required for code (addon, plugin, slicer); optional for a connector, which is data only.
privacyOptionalOptional: an https link to your privacy statement. The review asks whether it says where the data goes.
supportRequiredAn https link or a mailto: address for shops that need help.
screenshotsOptionalOptional: up to 8, each { url, alt }, url https, alt up to 140 characters.
deprecatedOptionalOptional: true when you no longer maintain it. Installed copies keep working; the page says so.
transferredFromOptionalSet by Khayt after an ownership transfer: the previous publisher’s name.

Every piece of your text is shown as text. Nothing in a listing is read as HTML, and outside links open with rel="noopener noreferrer".

What a listing cannot say

A listing describes; it never grants. It may not carry permissions, fields, domains, scopes, events, actions, secrets, refresh, price, signature. The permissions a page shows are worked out from the signed manifest: the same rows the app’s consent sheet shows. A listing that tries is refused, for example:

checkListing
✕ domains: a listing cannot say what an item may do; that comes from its signed manifest
✕ publisher.verifiedDomain: set by Khayt when the domain is proven, never in a listing

Who it is from

Your publisher namespace is reverse-DNS, like com.example, and every id you list sits under it. You prove the domain to Khayt once, with a DNS TXT record khayt-publisher=<token> or a file at https://example.com/.well-known/khayt-publisher. The name and the verified badge on your pages come from that record, never from a listing, so nobody can appear as Khayt or as you.

Review

  1. Send the manifest and the listing to Khayt. While the directory is new, that is by email to support@khaytapp.com.
  2. Automated checks: the manifest passes the app’s validator, its id is in your namespace, its version is higher than the last, and every domain serves https from a public address.
  3. A person reviews it, always for a first listing, wider permissions, a new domain or code. They see the consent sheet exactly as a shop would, and ask whether each field makes sense for what the item says it does.
  4. Khayt signs it and adds it to the signed index. Only then can a shop install it, and only then does the page offer it.

Listings are free. There are no paid items in this version.

Downloads and reports

Anything a page offers to download comes from https://khaytapp.com only, with the SHA-256 and size Khayt signed, and the page can check a downloaded file on the shop’s own computer. Every page has a Report button (malware, privacy, broken, impersonation, other). Khayt can withdraw a version, which pauses it on every device with the reason shown.
