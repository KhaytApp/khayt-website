How Khayt reviews what it lists

Nothing reaches a shop until a person at Khayt has reviewed it and Khayt has signed it. Your copy of Khayt checks that signature itself, so even this website cannot change what gets installed.

DRAFT, hidden: this directory is not public, and nothing on it can be installed yet.

Before anything is listed

  1. Automatic checks

    Every version: the manifest passes Khayt’s own validator, every address it sends to is a public HTTPS host, and it asks for nothing the app does not deliver. For code, also: a scan for secrets and malware, a dependency audit, and a check that the public source builds the same file.

  2. A person reviews it

    Always for a first listing, anything that asks for more than before, a new address, anything with code, and the first version after an item changes hands. The reviewer sees the consent screen exactly as a shop will.

  3. Khayt signs it

    With a key kept offline, never on this website or its servers. Every file is listed with its SHA-256 and size in a signed index.

What you can check yourself
  • What an item sends, and where, is worked out from its signed bytes, not typed by its publisher.
  • Every file shows its signed SHA-256, and the page can check the file you downloaded, on your computer.
  • Khayt verifies the hash and the signature again before it installs anything.
After it is listed
  • An update that asks for more waits until you agree; the old version keeps working.
  • Khayt can withdraw a version, and that turns it off in every shop that has it, with the reason.
  • Every item has a Report button, and a person at Khayt reads every report.

List your connector or plugin

  1. Build it

    Write a connector manifest against the schema, or a slicer plugin with its source public. Start from Khayt’s samples, which are MIT.

  2. Send it

    Email support@khaytapp.com with a link to the source and your privacy statement.

  3. Review and signing

    Khayt runs the checks above, reviews it, and signs it into the directory. You hear back by email, with every note.

The rules

  • Anything with code must publish its source. Data-only items (a connector manifest) may be closed.
  • Free only, for now.
  • It may send only the fields it declares, to the addresses it declares. Khayt shows those to the shop before install, and enforces them.
  • A name may not suggest it comes from someone it does not: an unofficial connector for a service says so.

Developer terms come before Khayt accepts outside submissions.
